Kebijakan Privasi

Sabolog (“Aplikasi”) menghormati privasi Anda dan berupaya menyediakan layanan yang dapat Anda gunakan dengan percaya diri. Kebijakan ini menjelaskan cara Aplikasi menangani data.

1. Kebijakan dasar

Aplikasi tidak mengirim atau mengumpulkan tugas, kategori, atau catatan dalam aplikasi lainnya yang Anda masukkan di server yang dioperasikan oleh pengembang. Data ini umumnya disimpan di perangkat Anda.

Jika Anda menggunakan pencadangan iCloud, data yang dicadangkan disimpan di penyimpanan iCloud Anda sendiri yang terkait dengan Apple Account Anda. Aplikasi juga dapat menggunakan layanan periklanan seperti Google AdMob. Penyedia periklanan dapat mengumpulkan pengidentifikasi iklan, informasi perangkat, informasi penggunaan, dan data lain yang terkait dengan penayangan iklan.

2. Informasi yang ditangani oleh Aplikasi

Aplikasi dapat menyimpan informasi yang Anda masukkan pada perangkat Anda untuk menyediakan fitur-fiturnya. Informasi ini digunakan untuk menyediakan, menampilkan, mencatat, dan memulihkan data aplikasi. Pengembang tidak mengirim, menyimpan, atau melihat data dalam aplikasi Anda di server eksternal.

3. Dimana data disimpan

Data aplikasi umumnya disimpan di perangkat Anda. Jika Anda mengaktifkan pencadangan iCloud, data yang dicadangkan akan disimpan di penyimpanan iCloud Anda sendiri. Manajemen data, sinkronisasi, penyimpanan, dan pemulihan di iCloud menggunakan layanan iCloud Apple. Pengembang tidak dapat melihat, mendapatkan, atau mengelola cadangan yang disimpan di iCloud Anda.

4. Pencadangan iCloud

Aplikasi mungkin menyediakan fitur cadangan iCloud untuk kenyamanan Anda. Cadangan disimpan di penyimpanan iCloud Anda sendiri yang terkait dengan Apple Account Anda. Pengembang tidak dapat melihat, mendapatkan, atau mengelola data cadangan iCloud Anda.

5. Pemberitahuan

Aplikasi dapat memberikan pemberitahuan berdasarkan pengaturan Anda. Notifikasi dikelola di perangkat Anda. Anda dapat mengubah izin notifikasi, menonaktifkan notifikasi, atau menyesuaikan waktunya di pengaturan perangkat Anda atau di Aplikasi.

6. Periklanan

Aplikasi dapat menggunakan layanan periklanan pihak ketiga seperti Google AdMob. Penyedia periklanan dapat mengumpulkan informasi berikut untuk menampilkan iklan, mengukur efektivitasnya, mencegah penyalahgunaan, atau mengoptimalkan iklan

  • Pengidentifikasi iklan
  • Informasi perangkat
  • alamat IP
  • Informasi penggunaan aplikasi
  • Informasi tentang tayangan dan interaksi iklan
  • Log kerusakan dan informasi kinerja

Kebijakan privasi masing-masing penyedia periklanan mengatur penanganan informasi ini. Nama tugas yang Anda masukkan dan catatan dalam aplikasi lainnya tidak dikirim ke penyedia periklanan melalui server pengembang.

Untuk detail tentang penanganan data oleh Google, lihat Kebijakan Privasi Google dan Google AdMob.

7. Berbagi dengan pihak ketiga

Pengembang tidak memberikan informasi tugas Anda atau catatan dalam aplikasi lainnya kepada pihak ketiga, kecuali jika diwajibkan oleh hukum. Namun, penyedia periklanan pihak ketiga dapat mengumpulkan informasi yang diperlukan untuk menayangkan iklan.

8. Data dikirimkan di luar perangkat Anda

Aplikasi tidak mengirimkan tugas yang Anda masukkan atau catatan dalam aplikasi lainnya ke server yang dioperasikan oleh pengembang. Data dapat disimpan atau dikirim ke luar perangkat Anda dalam situasi berikut

  • Anda menggunakan cadangan iCloud.
  • Layanan periklanan pihak ketiga seperti Google AdMob mengumpulkan informasi yang diperlukan untuk menayangkan iklan.
  • Sistem operasi atau SDK periklanan mengumpulkan log kerusakan, diagnostik, atau informasi kinerja.

9. Menghapus data

Anda dapat menghapus tugas terdaftar, tugas selesai, dan data lainnya menggunakan fitur Aplikasi. Menghapus Aplikasi dari perangkat Anda juga akan menghapus data Aplikasi yang disimpan secara lokal. Jika Anda menggunakan cadangan iCloud, Anda mungkin perlu menghapus data yang disimpan di iCloud melalui perangkat Anda atau pengaturan iCloud.

10. Keamanan

Aplikasi berupaya menangani data Anda dengan tepat. Data umumnya disimpan di perangkat Anda atau, jika Anda menggunakan cadangan iCloud, di penyimpanan iCloud Anda sendiri. Karena sifat komunikasi internet, perangkat, layanan cloud, dan layanan periklanan, keamanan lengkap tidak dapat dijamin.

12. Perubahan kebijakan ini

Pengembang dapat mengubah kebijakan ini sebagai respons terhadap perubahan undang-undang, konten layanan, fitur, atau layanan periklanan. Perubahan akan diumumkan sebagaimana mestinya di Aplikasi atau di halaman web publik.
