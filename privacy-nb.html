Personvernerklæring

Sabolog (“Appen”) respekterer ditt privatliv og streber etter å tilby en tjeneste du kan bruke med tillit. Denne policyen forklarer hvordan appen håndterer data.

1. Grunnleggende policy

Appen sender eller samler ikke inn dine angitte slakkoppgaver, kategorier eller andre poster i appen på servere som drives av utvikleren. Disse dataene lagres vanligvis på enheten din.

Hvis du bruker iCloud-sikkerhetskopier, lagres de sikkerhetskopierte dataene i din egen iCloud-lagring knyttet til din Apple Account. Appen kan også bruke annonseringstjenester som Google AdMob. Annonseleverandører kan samle inn annonseringsidentifikatorer, enhetsinformasjon, bruksinformasjon og andre data relatert til visning av annonser.

2. Informasjon som håndteres av appen

Appen kan lagre informasjon du skriver inn på enheten din for å tilby funksjonene. Denne informasjonen brukes til å gi, vise, registrere og gjenopprette appdata. Utvikleren sender, lagrer eller viser dataene dine i appen på eksterne servere.

3. Hvor data lagres

Appdata lagres vanligvis på enheten din. Hvis du aktiverer iCloud-sikkerhetskopier, lagres sikkerhetskopierte data i din egen iCloud-lagring. Databehandling, synkronisering, lagring og gjenoppretting i iCloud bruker Apples iCloud-tjenester. Utvikleren kan ikke se, skaffe eller administrere sikkerhetskopier som er lagret i iCloud.

4. iCloud sikkerhetskopier

Appen kan gi iCloud sikkerhetskopieringsfunksjoner for din bekvemmelighet. Sikkerhetskopier lagres i din egen iCloud-lagring tilknyttet din Apple Account. Utvikleren kan ikke se, skaffe eller administrere sikkerhetskopieringsdataene dine for iCloud.

5. Varsler

Appen kan gi varsler basert på innstillingene dine. Varsler administreres på enheten din. Du kan endre varslingstillatelse, deaktivere varsler eller justere tiden deres i enhetsinnstillingene eller i appen.

6. Reklame

Appen kan bruke tredjeparts annonseringstjenester som Google AdMob. Annonseleverandører kan samle inn følgende informasjon for å vise annonser, måle effektiviteten, forhindre misbruk eller optimalisere annonsering

  • Annonseidentifikatorer
  • Enhetsinformasjon
  • IP-adresser
  • Informasjon om appbruk
  • Informasjon om annonsevisninger og interaksjoner
  • Krasjlogger og ytelsesinformasjon

Hver annonseleverandørs personvernpolicy styrer håndteringen av denne informasjonen. De angitte oppgavenavnene dine og andre poster i appen sendes ikke til annonseleverandører gjennom utviklerens servere.

For detaljer om Googles håndtering av data, se Googles retningslinjer for personvern og Google AdMob.

7. Deling med tredjeparter

Utvikleren gir ikke oppgaveinformasjonen din eller andre poster i appen til tredjeparter, med mindre det er påkrevd ved lov. Tredjeparts annonseleverandører kan imidlertid samle inn informasjon som er nødvendig for å vise annonser.

8. Data som overføres utenfor enheten din

Appen overfører ikke dine angitte oppgaver eller andre poster i appen til servere som drives av utvikleren. Data kan lagres eller overføres utenfor enheten din i disse situasjonene

  • Du bruker iCloud sikkerhetskopier.
  • Tredjeparts annonseringstjenester som Google AdMob samler inn informasjon som er nødvendig for å vise annonser.
  • Operativsystemet eller annonserings-SDK-ene samler inn krasjlogger, diagnostikk eller ytelsesinformasjon.

9. Sletting av data

Du kan slette registrerte oppgaver, fullførte oppgaver og andre data ved å bruke appens funksjoner. Sletting av appen fra enheten din sletter også appens lokalt lagrede data. Hvis du bruker iCloud sikkerhetskopier, må du kanskje slette data som er lagret i iCloud gjennom enheten eller iCloud-innstillingene.

10. Sikkerhet

Appen streber etter å håndtere dataene dine på riktig måte. Data lagres vanligvis på enheten din eller, hvis du bruker iCloud-sikkerhetskopier, i din egen iCloud-lagring. På grunn av arten av internettkommunikasjon, enheter, skytjenester og reklametjenester, kan fullstendig sikkerhet ikke garanteres.

11. Kontakt

For spørsmål om denne policyen, kontakt leo.indieappworks+sabolog@gmail.com.

12. Endringer i denne policyen

Utvikleren kan endre denne policyen som svar på endringer i lov, tjenesteinnhold, funksjoner eller reklametjenester. Endringer vil bli annonsert på passende måte i appen eller på en offentlig nettside.
